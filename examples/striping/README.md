# 纵带划分（striping）

把一个整数平面范围和一组轴对齐矩形地物，划分成指定数量的纵带，使各带
**有地物覆盖的面积尽量均匀**。这是给制图同事切分作业面用的离线工具，
不依赖运行中的 Meridian 服务。

## 语义

- 坐标与数据库一致：矩形是半开的 `[min_x,max_x) × [min_y,max_y)`，所有切线
  坐标都是整数，且每条纵带严格正宽。
- 覆盖面积 `covered` 指至少被一个地物覆盖的面积；重复面积 `repeated` 指至少
  被两个地物覆盖的面积（被三个地物覆盖仍只算一单位重复，不按次数累加）。
- 范围内的空缝对两项测度都没有贡献，因此**空缝不会被算作任何一带的覆盖
  增长**；它只会体现在该带的 `uncovered` 里。
- 与范围只有零面积接触（例如只碰到开右边）或完全在外的地物会被忽略，并在
  `trace.ignored_outside_range` 中计数；部分相交的地物按范围剪裁后计入。
- 优化目标：最小化各带覆盖面积相对均匀目标 `总覆盖 / 带数` 的最大偏差，
  整数约束下做不到完全均匀时报告精确的有理偏差。

## 输入

```json
{
  "range": { "min_x": 0, "min_y": 0, "max_x": 20, "max_y": 10 },
  "bands": 4,
  "description": "可选的用途说明，会原样写回报告",
  "features": [
    { "id": "west-field", "class": "survey",
      "box": { "min_x": 1, "min_y": 1, "max_x": 6, "max_y": 9 } }
  ]
}
```

## 运行

```sh
go run ./cmd/striping -input examples/striping/wide-gap.json \
  -output examples/striping/wide-gap.report.json
# 不传 -input 时从标准输入读取；不传 -output 时写到标准输出
```

## 报告内容

- `cuts`：实际内部切线的整数绝对坐标；`stripes[].from_x/to_x` 是每带的真实
  边界，`width` 为正宽。
- 每带给出 `covered`、`repeated`、`uncovered` 以及相对均匀目标的精确分数
  偏差 `deviation`，并列出相交的输入地物 `feature_ids` 便于追溯。
- `quality`：均匀目标、最大/平均绝对偏差、平方偏差和、求解路径与最优性说明。
- `checks`：切线为范围内严格递增整数、各带正宽且无缝无叠铺满、覆盖/重复
  分量加总等于总量、覆盖加未覆盖等于范围面积等不变量的自检结果。
- `trace`：原始范围、全部输入形状（含 ID 与类别）、扫描线常量段以及被忽略
  地物数量，使报告可以完全回溯到输入。

## 两个示例

| 文件 | 布局 | 预期 |
| --- | --- | --- |
| `continuous-slab.json` | 无空缝的连续大片，含高度差和重叠 | 按覆盖面积而非宽度均分，重复面积正确归集 |
| `wide-gap.json` | 左右两片之间有 4 单位宽空缝 | 四带覆盖恰好各 24、偏差为 0，空缝只增加 `uncovered` |

## 求解路径

- `unit-width`：带数等于范围整数宽度，每列一带。
- `exact-dp`：宽度较小时的字典序动态规划，同时最小化最大偏差与平方偏差。
- `minimax-reachability`：大宽度下的分层可达性 DP（每层 O(宽度)）加二分，
  精确最小化最大偏差，并按覆盖分位点确定性地打破平局。
